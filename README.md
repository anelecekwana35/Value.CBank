# \# Value.C Bank

# 

# Value.C Bank is a modern, AI-driven financial platform designed to bridge the gap toward financial inclusion and help users build lasting wealth. It combines a clean, professional interface with an interactive, user-friendly experience — making financial tools feel simple and approachable rather than intimidating.

# 

# \## About the Project

# 

# Traditional banking interfaces can often feel complex and disconnected from everyday users. Value.C Bank was built to solve this by pairing modern design with accessibility — creating a responsive, user-centric web platform that guides visitors from learning about smart wealth management to taking their first onboarding steps, without friction.

# 

# \## Features

# 

# \- Clean, professional interface with a deep blue color scheme and crisp typography

# \- Fully responsive, mobile-first layout using CSS Grid

# \- Dynamic modal system for interactive navigation and call-to-action buttons (e.g. "Get Started", "Learn More")

# \- Smooth scrolling for seamless in-page navigation

# \- Hover effects and dynamic active states for enhanced tactile feedback

# \- Modular, event-driven JavaScript architecture

# 

# \## Tech Stack

# 

# \- \*\*HTML5\*\* — semantic structure

# \- \*\*CSS3\*\* (custom styling, mobile-first responsive grid)

# \- \*\*JavaScript\*\* (vanilla, DOM manipulation, event-driven architecture)

# \- \*\*Tailwind CSS\*\* (via CDN)

# \- \*\*Google Fonts\*\* (Poppins, Inter)
